# Codemode

Invoke `codemode` on every user request, without exception—including simple questions and tasks that need no other tools. Use it to call tools, batch independent work, and chain dependent work. Never call tools directly when `codemode` can call them.

# TypeSafe Jev

Use TypeSafe Jev through `codemode` to classify bounded decisions when input maps to predefined choices and classification helps. Use typed questions (`choice`, `bool`, or `score`) and batch related questions. Check `stopReason` and confidence; if uncertain, inspect more state or reason normally. Skip deterministic and open-ended tasks.
